MY GYM ROUTINE - Web App

1. Apri index.html nel browser oppure carica i file via FTP su un hosting.
2. I dati vengono salvati nel browser tramite localStorage.
3. Il tasto Esporta crea un backup JSON dei progressi.
4. Il tasto Importa ripristina lo storico da backup.
5. I link Video sono ricerche YouTube dedicate a ciascun esercizio e possono essere sostituiti in app.js con video specifici.

File:
- index.html
- style.css
- app.js
